# Great Person map art

Generated with the built-in ImageGen tool on 2026-10-16. The original transparent PNG is retained here; `manifest.json` records the original hash, measured crop rectangles, runtime paths, alpha bounds and runtime hashes. All nine runtime WebP files together occupy approximately 315 KB.

The brief requested a transparent 3-by-3 atlas of full-body, right-facing historical game miniatures in warm realistic painted earth pigments, cream linen, burgundy, aged brass and muted navy. Each cell contains one class archetype, with transparent padding, no labels, background, cast shadows or battle poses. Row order:

1. General: ancient bronze armor, crimson cloak and campaign map; admiral: navy captain and telescope on a wooden command skiff; engineer: architect with drafting scroll and measuring compass.
2. Scientist: cream/teal scholar with astrolabe and book; merchant: Silk Road robes, ledger and purse; prophet: ivory/purple elder with staff and scroll.
3. Writer: East Asian indigo scholar with scroll/brush; artist: Renaissance painter with palette; musician: green court musician with lute.

These are nine shared class archetypes, not 256 individually authenticated historical likenesses. Every catalogue person resolves to its public class and retains its historical name. Original cell alpha bounds were cropped and resampled into 256-pixel transparent WebP assets, using maximum visible width 224, maximum visible height 210 and baseline y=225. No generative alteration was performed during slicing.

The current game's map uses painted sprites. Existing land/ship rigs retain idle/activation and loading-fallback motion; Great People do not need attack or death sheets because they cannot be attacked. Naval transport retains the existing independent transport hull. Assets are requested only when a visible Great Person needs them, and shared across the 2D/3D renderer modules. Ordinary unit art is the loading fallback.

## Painted movement update - 2.29.4

Three additional original ImageGen sheets each contain four columns and three class rows. They use the original nine-class atlas as the identity reference, preserving costumes, props and facing. Each class has four painted walk-cycle phases (left contact, passing, opposite contact, opposite passing); the admiral changes oar phases instead. The prompt required alpha transparency, fixed body scale, equal cells, consistent foot/keel baseline, padding, and no labels, ground, extra characters or attack poses.

The full original sheets are command-movement-original.png, scholars-movement-original.png and culture-movement-original.png. prepare-movement.py measures alpha gaps and slices the original cells. One common scale per class keeps all four poses consistent, with baseline y=225 in a 256-pixel cell. It creates nine 1024-by-256 runtime sheets named `<class>-move.webp`; movement-manifest.json records source hashes, measured rectangles, scale and runtime hashes. The final visible poses are not generated by deforming the idle artwork. Both real map renderers select these four frames while walking; reduced motion keeps the idle pose.
