# Real-world natural-wonder art expansion

31 original transparent PNGs generated with the built-in imagegen tool, one request per real site, `transparent_background: true`. Four existing real-site PNGs are reused from the first batch. The active [manifest](manifest.json) lists35 sources, dimensions, SHA-256 hashes, subjects and runtime WebPs, totaling1,669,286 bytes. No Civilization assets were extracted. Sharp only resized and encoded; it synthesized no content.

The four fictional runtime sprites are retired. Their original generator files remain historical, outside this active inventory. The importer consumes a private local receipt and does not remove generator originals. Three bounded contact sheets and actual-browser screenshots are retained in ignored task output.

Each of the31 complete prompts substitutes its manifest `subject` into this exact template:

> Create ONE isolated transparent-background map landmark sprite for Unwritten World, a historical Renaissance civilization strategy game. Real-world subject: {subject} This must depict the characteristic actual geology and silhouette, not an invented fantasy place. Elevated isometric strategy-camera view, the whole miniature object fits within a square canvas with at least 15% transparent margin. Tactile finely painted oil/gouache brushwork, atlas-like miniature realism, restrained parchment ochre, lapis and verdigris palette, warm brass-era light. Clearly distinguishable silhouette and readable at 96 pixels. An organic irregular natural base only; no pedestal, game hexagon, game hex grid, frame, UI, letters, numbers, icon badge, collage, opaque backdrop or rectangular terrain tile. Natural alpha edges and soft transparent mist where appropriate. No architecture, people, roads, flag or invented ornamental structures. This is a real compositing asset matching hand-painted historical map scenery, not a screenshot or concept sheet.

The four reused assets retain their original first-batch prompts and hashes.
