## Public source and local records

The public source includes the game implementation, native AI source, SDK, MCP/API adapters, reusable test and packaging scripts, and curated documentation. Historical test outputs, comparison results, model/agent reviews, private development notes, local client configuration, credentials, browser profiles and saved games remain local.

Older root-level feature and review documents are retained locally because they mix reusable explanations with session history. Current usage and rule documentation is maintained under `docs/`. Excluding private records does not withhold the implementation or prevent others from generating their own test results.
