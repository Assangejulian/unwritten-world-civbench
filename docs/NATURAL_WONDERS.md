# Natural wonders

New worlds enable natural wonders by default. The New Game switch and `naturalWondersEnabled: false` disable them. Older worlds retain their original geography: loading does not add landmarks, discovery records or rewards. DIY means original game effects for physically real natural places. The active catalogue contains exactly **35 real sites**, with no fictional identities. These are adaptations for this game, not exact Civilization VI rules or scientific yield claims.

## Placement and authority

35 is the pool size, not a required number on each map. Target count is `clamp(round(sqrt(tileCount) / 14), 2, 8)`; impossible geography can reduce it. The independent RNG is `seed + ':natural-wonders:real35:v1'`, after ordinary geography, starts, resources and encounters. Each key appears at most once. Sources remain more than five hexes from starts and at least eight hexes apart, using wrapped hex distance. No terrain is transformed to force a candidate. Existing world/combat/encounter RNG streams remain unchanged.

The public definitions carry explicit geography constraints. River falls need connected riverbanks; coastal formations need water/land neighborhoods; desert formations, cold lakes/glaciers and mountain landmarks use matching terrain. Lakes currently use coast terrain as an abstraction; this change does not generate new inland-water topology or multi-tile features.

Underlying terrain determines movement and river crossings. Roads avoid protected sources. ## Discovery, disasters and AI

Each civilization receives `round(10 * gamePace.factor)` culture and +2 era score once per discovered landmark. There is no extra first-discoverer award. Observing or reloading known sites does not pay again.

Auras apply only after discovering their source. They exclude cities, districts, water, mountains and other landmarks, and cap at +2 per yield on each ordinary tile. District natural adjacency caps at +4. Climate fertility retains its independent +2 total cap. Disasters damage ordinary surrounding units and infrastructure; landmarks remain permanent.

Fuji, Bromo, Vesuvius and Etna are eruption origins in the existing disaster system, with real damage and bounded fertility. Non-erupting mountain landmarks such as Everest and Zhangjiajie are excluded from random ordinary-mountain volcano selection. Kilimanjaro is not configured as an active eruption source; Dallol is represented as a geothermal field. The Vatnajokull ice-cap abstraction does not simulate its subglacial volcanoes or glacial outburst floods. River falls retain ordinary flood risk. These rules simplify reality for the benchmark.

Human, native AI and MCP use the same discovered identities and numeric yields. Hidden sources give neither identity nor aura. Remembered sites retain static known landmarks and dimmed artwork, without current hidden weather. Other civilizations' discoveries stay private. Great-person map surveys immediately project natural metadata into remembered terrain; resurveying a known source area preserves its aura without deferring that bonus until reload. `npm run check:natural-reveal` covers known, newly discovered and still-hidden sources through actual Hanno activation and exact save restoration.

MCP: `game_observe({section: "natural_wonders"})` returns the querying civilization's discovered sites. `game_rules({kind: "natural_wonder", limit: 40})` returns the complete public 35-entry catalogue without map locations. Normal catalogue queries paginate; inspect/options/action authority remains unchanged. No player action manufactures a landmark.

The shared native C++ policy evaluates these definitions numerically, without35 site-specific exceptions. Settlement considers known natural district opportunities and visible fertility alongside public disaster exposure. District shortlists and final native scores account for aura/fertility lost on an ordinary plot. Human and external-agent menus retain their existing ordering; private placement scores are removed from external previews. Builder forecasts recompute auras after feature changes: lumbermills retain eligible forest bonuses while clearing forest for resources loses them. No hidden landmark or remote current weather steers the AI. Run `npm run check:environment-ai` after building the native players.

## Artwork and verification

35 transparent 384px runtime WebPs total **1,669,286 bytes**. Four existing real-site originals are reused from [the first art batch](../art-source/natural-wonders-20261030/README.md); 31 new original PNGs and provenance are in [the real-site expansion](../art-source/natural-wonders-real35-20261030/README.md). The four fictional runtime assets have been removed; their original PNGs remain an explicitly retired historical archive. Both map renderers use lazy painted sprites and omit generic peak/tree scenery on visible source tiles. Fog, depth and async static invalidation remain authoritative.

Run `npm run check:natural-wonders`, `npm run check:natural-wonders-native`, `npm run check:natural-wonders-ui` and `npm run check:environment-mcp`. Focused checks cover catalogue geography/yields, negative placements, nonvolcanic exclusions, deterministic generation, fog/rewards, city/district/scientist effects, protection, eruption damage/fertility, legacy restoration, compiled drivers, SDK queries and real HTTP/browser rendering. Generated reports and historical results remain local. These checks do not establish whole-match balance or paid external-model performance.

A normal full backend restart activates changes. Preserve paused matches until the operator chooses to restart. Old worlds do not receive retroactive landmarks.
