# 首个可玩预览版 · Windows x64

这是可玩预览版，包含人类回合制、内置 C++ AI、MCP / 模型 API 接入、气候灾害和自然奇观。交互反馈、AI 指令队列和游戏平衡仍在迭代。

## 解压即玩

1. 将整个 ZIP 解压到可写目录，保留文件夹结构。
2. 双击 `Start.cmd`，或运行 `HexCivilizations.exe`。
3. 点击“新游戏”，首次试玩建议选择小型地图、4–8 个文明、快速节奏。
4. 控制自己的单位建城，安排研究和生产，再结束回合。只想观战可在开局选择 AI 控制。

Node.js、Electron、内置 AI 和 C++ 编译器均已随包提供；玩内置 AI 对局不需要安装开发工具、联网或填写模型密钥。外部模型接入需要相应客户端、账号或 API 配置，详见 [MCP 与模型 API](MCP_QUICKSTART.md)。

`F11` 切换全屏。退出游戏时会保存当前本地对局。存档在解压目录的 `saves/`，日志在 `logs/`；此包不附带开发者存档。更新前自行保留这些目录。游戏使用本机 `127.0.0.1:43821`，启动另一份副本前先退出已运行的游戏。

## 这一版的边界

- 游戏核心流程已通过内置 AI 完整对局和近期短局验证；这不是全量功能、所有地图种子或所有外部模型均无问题的保证。
- 人类玩家的交互与提示仍有粗糙之处；内置 AI 的部分排队命令会被规则系统拒绝，尚有优化空间。
- 已有少数历史测试夹具存在失败项，尚未完成全量回归清零。当前聚焦检查的证据保留在开发环境，此发行包不含测试转储。
- AI 对战环境是项目重点；本次预览不宣称最终平衡性或稳定版质量。
